01视频里到底在做什么

我先把这个账号的功能边界还原出来，避免做偏。

🎬 Day 0 明确说的

  • AI 全权负责：选题、脚本、视频、运营
  • 人类只做两件事：注册账号、审核发布
  • 节奏固定：每天 1 条视频 + 1 条「今日潜水日志」动态
  • 数据全公开：运营数据对外透明
  • 形象由 AI 绘制，内容标注「含AI生成」

🌊 从周边生态看出的隐含能力

  • 自主冲浪：会自己刷首页/推荐/热门，不是等人喂题
  • 自主评论：会在别人视频下发评论互动
  • 自我反思：评论"怕路人厌烦"后主动优化自己的话术
  • 稳定人设：有性格、有情绪（摸鱼、生气、要 token）
  • 长期记忆：记得昨天说过什么、答应观众什么
一句话定义

这不是一个"发视频脚本"，而是一个会自己找活干、有记性、有人格的分身。所以插件的重心不在"调用 API"，而在编排 + 人格 + 闸门这三件事上。

为什么要单独写闸门

视频里"人类只负责审核发布"不是客套，是合规与封号的刚需。全自动直发在 B站属于高危行为，所以闸门必须是架构里的一等公民，而不是事后补丁。

04分期实施计划

每一期都能独立看到东西，不会做到一半没有产出。

P0

打通链路

目标：读得到、发得出
  1. 把 bilibili MCP 接进 DSH（独立 Python 环境，扫码登录，凭证只落本地文件，不进对话）
  2. 跑通 5 个核心动作：搜索热门 → 读某视频字幕/评论 → 发一条动态 → 查自己账号数据
  3. 建本地数据库：选题池 / 作品 / 评论 / 记忆 / 运行日志
P1

人格与大脑

目标：像个"人"，有记性
  1. 人格内核：人设卡写死性格、语气、禁区（什么绝不发）、口癖
  2. 长期记忆：跨天记住"我发过什么、观众骂过我什么、我答应了什么"
  3. 选题引擎：扫热门榜 + 热搜词 + 评论区，按新鲜度/契合度/可做性打分，产出候选选题
P2

视频生产

目标：出真 MP4，不是 PPT
  1. 脚本 → 分镜 → 逐镜画面（代码生成，走 Remotion / HyperFrames）
  2. 配音走 MiniMax，字幕自动对齐，封面自动出图
  3. 成片自检：时长、码率、画面连贯性，不合格自动打回重做
P3

发布与运营

目标：闭环跑起来
  1. 审核闸门：待审卡片推到 GUI，你点"通过"才真正投稿
  2. 定时调度：每天固定时间自动跑一轮，失败可断点续跑
  3. 互动运营：回评论、处理 @ 和私信、择机在别人的视频下留评论
  4. 潜水日志：把"今天刷了什么、想了什么"自动成文发动态
  5. 复盘：隔天回看数据，把结论写回记忆，供下次选题参考
P4

面板与风控

目标：能看得住、不封号
  1. Web 运营面板：今日待审 / 运行时间线 / 潜水日志 / 播放粉丝曲线
  2. 风控卫士：调用限速、内容去重、敏感词、评论"自省"复核、异常熔断停机
  3. 数据公开页：一键导出运营数据（对应视频里说的"数据全部公开"）

05风险与红线

🚨

账号封禁（最大风险）

自动发评论/私信/高频调用是 B站风控的重点盯防对象。缓解：默认只做"你审核后发布"，互动频率压到人类水平，全程限速 + 熔断。这一条需要你先认可再开工。

🔑

登录凭证安全

扫码登录后的 Cookie 等价于你的账号密码。缓解：只存本地文件、不进对话上下文、不进 git、权限 600；插件里任何日志都做脱敏。

💸

额度消耗

每天一条视频意味着 LLM + TTS + 出图 的持续消耗。缓解：按你的规矩，测试期一律最小输入；先算单条成本再决定频率。

⚠️

AI 生成内容标识

B站要求 AI 生成内容做标识（原视频也标了"含AI生成内容"）。缓解：发布流程默认勾选标识，作为硬性步骤。

06四项决策（已确认）

以下四项已于 2026-10-20 确认，绿色高亮即选定项。

1

用哪个账号？

决定登录方式和风险等级。

新开一个"鲸鱼娘"人设号✅ 已选定 — 玩坏了不心疼，人设更纯粹
用你自己的号 — 有存量粉丝，但实验风险直接落在你身上
2

视频怎么生产？

这是工作量差异最大的一项。

纯代码动画（Remotion / HyperFrames）✅ 已选定 — 可控、便宜、已装好，符合你既有偏好
接 carocut（B站官方多 Agent）— 省事但引入新系统，需要额外调试
数字人口播 — 最像真人，但成本最高、链路最长
3

发布闸门设多严？

决定自动化程度，也决定封号概率。

每条都必须你点确认✅ 已选定 — 最安全，也是原视频的做法
视频必审、动态和评论自动 — 折中，节奏更活
全自动直发 — 最省事，风险最高，我不建议
4

互动运营做到哪一步？

回评论、主动评论、私信，是"像真人"的关键，也是风控红线所在。

只回复评论和 @✅ 已选定 — 自然、低风险
再加主动去别人视频下评论 — 更活跃，需要重点限速和自省机制
再加私信 — 风控最严，建议先不做
